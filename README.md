# Armaan Gill Portfolio

A responsive, single-page portfolio for Armaan Gill, built for GitHub Pages.
It uses plain HTML and CSS, so there is no installation or build step.

## Included content

- Robotics, autonomous systems, Linux, and technical troubleshooting profile
- Autonomous drone, person-following UGV, and haptic VR projects
- Systems diagnosis, cloud/container skills, RMIT education, and RoboCup recognition
- Email contact link

The public page intentionally omits the phone number from the resume. GitHub,
LinkedIn, project repository links, and project imagery can be added later.

## Publish with GitHub Pages

1. Create a new public repository on GitHub.
2. Add `index.html`, `styles.css`, `.nojekyll`, and this `README.md`.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

For the address `YOUR-GITHUB-USERNAME.github.io`, name the repository
`YOUR-GITHUB-USERNAME.github.io`.
